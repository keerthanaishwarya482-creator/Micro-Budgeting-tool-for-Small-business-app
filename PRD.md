# Product Requirements Document (PRD)

## 1. Project Name

**Micro Budgeting Tool for Small Business**

## 2. Problem Statement

Small businesses need to track their daily income and expenses.

Managing these details manually can be difficult and may lead to mistakes.

This application provides a simple way to record and manage business transactions.

## 3. Objective

The main objective is to help small business owners easily manage their income, expenses, and available balance in one place.

## 4. Target Users

* Small business owners
* Shop owners
* Small-scale entrepreneurs

## 5. Main Features

### 5.1 Dashboard

* Display total income
* Display total expenses
* Display current balance
* Show recent transactions

### 5.2 Add Transaction

Users can add:

* Transaction date
* Transaction type
* Amount
* Category
* Description

Transaction types:

* Income
* Expense

### 5.3 View Transactions

Users can view all recorded transactions.

### 5.4 Edit Transaction

Users can update an existing transaction.

### 5.5 Delete Transaction

Users can delete an unwanted transaction.

### 5.6 Search Transaction

Users can search transactions by:

* Description
* Category
* Transaction type

## 6. Database

The application uses MySQL.

### Transaction Table

Fields:

* Transaction ID
* Transaction Date
* Transaction Type
* Amount
* Category
* Description

## 7. Technologies

* **Frontend:** HTML, CSS
* **Backend:** Python Flask
* **Database:** MySQL
* **Version Control:** GitHub

## 8. Expected Result

The final application provides a simple dashboard where a small business owner can record, search, edit, and delete transactions and understand their income, expenses, and remaining balance.
