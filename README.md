# Micro Budgeting Tool for Small Business

A simple budgeting tool that helps small businesses track their daily income and expenses.

It provides an easy way to manage transactions and monitor the available balance.

## Features

* Add Income and Expense
* View Transactions
* Search Transactions
* Edit Transactions
* Delete Transactions
* Calculate Total Income
* Calculate Total Expenses
* Display Current Balance

## Technologies

* HTML
* CSS
* Python
* Flask
* MySQL
* GitHub
